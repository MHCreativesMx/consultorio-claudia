# Consultorio de Claudia Espinosa

Página móvil con video de bienvenida, ubicación interactiva y acceso para agendar por WhatsApp.

## Archivos

- `index.html`: página web adaptable a celulares y escritorio.
- `bienvenida-flow.mp4`: video de introducción generado con Google Flow.
- `poster.svg`: portada mostrada antes de reproducir el video.
- `favicon.svg`: icono de la página.

## Publicación

El sitio se puede publicar como página estática en GitHub Pages. Comparte la URL HTTPS que entrega GitHub; así los videos, el mapa y WhatsApp funcionan desde Android y iPhone sin instalar una aplicación.
